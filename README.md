# Подсчёт слов

Программа на JavaScript для подсчёта слов в тексте. Принимает строку, файл в кодировке UTF-8 или данные из стандартного ввода.

Для запуска нужен Node.js 18 или новее. Устанавливать зависимости не требуется.

## Запуск

Текст из командной строки:

```powershell
node word-counter.js "Привет, мир! Это простой пример."
# Количество слов: 5
```

Текст из файла:

```powershell
node word-counter.js --file README.md
```

Стандартный ввод в PowerShell:

```powershell
$OutputEncoding = [System.Text.UTF8Encoding]::new($false)
"Один два три" | node word-counter.js
# Количество слов: 3
```

Слова могут содержать буквы и цифры. Дефис и апостроф внутри слова не разделяют его: «кто-то» считается одним словом. Знаки препинания и эмодзи не учитываются.
