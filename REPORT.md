# Отчёт о выполнении

Репозиторий: https://github.com/fanronaldo777161/word-counter-git-practice

## 1. Программа и публикация

Создана программа `word-counter.js` на JavaScript, считающая слова в строке, файле или стандартном вводе. Проект опубликован в публичном репозитории, основная ветка — `main`. Использован существующий аккаунт `fanronaldo777161`.

Проверены семь случаев: пустая строка, пробелы, русский текст, дефисы и апострофы, числа, эмодзи и пунктуация, переносы строк и табуляция. Проверен запуск из командной строки; пример из README возвращает 5 слов.

Дополнительно проверены чтение `team.txt` (1 слово), стандартный ввод UTF-8 (3 слова) и отсутствующий файл (код завершения 1). Для передачи кириллицы через конвейер Windows PowerShell в README явно задана кодировка `$OutputEncoding` UTF-8.

## 2. Игнорирование .bin

В `.gitignore` добавлено правило `*.bin`. Создан локальный `ignored-example.bin`, выполнен `git add -- ignored-example.bin`. Git отказался добавлять игнорируемый файл. `git check-ignore -v ignored-example.bin` указал на правило в первой строке `.gitignore`; `git ls-files '*.bin'` вернул пустой результат. Сам проверочный bin-файл в репозиторий не опубликован.

- `90ec6e9` — фамилия Сихарулидзе в ветке `add-sikharulidze`, созданной от коммита с пустым файлом.

- `0792056` — коммит слияния PR #1.

GitHub не позволяет создать личный форк собственного репозитория в том же аккаунте. Владелец внёс фамилию через ветку и PR. Если преподаватель требует форк от каждого без исключений, нужно согласовать использование репозитория организации или другого владельца.

**Остаётся:** Чигрин создаёт форк из своего аккаунта, добавляет свою фамилию и отправляет PR; владелец принимает его. Действия второго участника не имитировались. Команды для старта именно с пустого файла и вариант через интерфейс GitHub приведены в README.

## 5. Выборочный перенос второго файла

Ветка `three-files` содержит три отдельных коммита:

1. `eb2cef6` — `first.txt`.
2. `da325e5` — `second.txt`.
3. `721590c` — `third.txt`.

Командой `git cherry-pick da325e5` в `main` перенесён только второй коммит; новый коммит — `662c477`. В `main` присутствует `second.txt`, а `first.txt` и `third.txt` остались в `three-files`.

Все демонстрационные ветки и метка опубликованы на GitHub.
